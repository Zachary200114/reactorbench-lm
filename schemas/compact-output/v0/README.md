# ReactorBench-LM compact output contract v0

This directory records the developmental `0.2.0` model-output language. The learned
sequence is a bounded, one-line `RB2` wire form; strict project target models remain
the source of truth and canonical JSON remains the audit/API representation.

The contract is intentionally marked `frozen: false` until the approved
training/validation target-length inventory is measured and the task-specific
generation caps are preregistered. Changes require a versioned contract update; the
historical Phase 6 v0.1 artifacts must not be overwritten.
